## 结论

- **数值表以国服技能说明（ActionTransient）为准**，回归只用来查漏和发现规则（不叠加、继承）
- **来源身上的减益和说明完全吻合**：雪仇 10.5% / 10.2%（魔 / 物），昏乱 10.7% / 4.2%，牵制 4.8% / 8.0%，武装解除 10.7%
- **Boss 本体上的减益对分身（同名的隐形单位）的伤害同样生效**：继承的雪仇在魔法伤害上估计 10.0%（1,818 次，区间 8.4~11.5%），武装解除 11.8%。物理伤害上继承的雪仇只有 3.6%（327 次），可能混进了同名普通小怪，暂不据此调整
- **行吟 / 策动 / 防守之桑巴互不叠加**（说明原文“无法…共存”），按组估计魔法 11.5%：98 级以上 15%、以下 10%，样本里两种都有
- **暗黑布道**估出魔法 4.9%（区间 1.1~8.5%），说明原文是物理 5%、魔法 10%，以说明为准；可能是和其他团减同时出现造成的干扰，待更多样本
- 回归发现并补进了数值表的：武装（队友身上的武装戍卫）15%、告解（全大赦）10%、通天眼 10%、世界树之干 10%、原初的血潮 10%
- 副本机制的易伤（受伤加重等）数值因技能而异，不收录在数值表里；现在取挂上它的那一行技能行里的修正字节
- 残差约 13~17%，远大于游戏本身 ±5% 的浮动，说明还有没建模的因素（距离衰减、按最大 HP 计算的伤害等），所以区间较宽；样本少于 100 的估计只作参考
