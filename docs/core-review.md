# core 代码审查（2026-10-07）

范围：`src/core/` 全部（约 6,800 行）、`src/data/mitigation.ts`、导入脚本 `scripts/import-game-data.ts` 和 `scripts/game-data/`。分四块审：护盾账本；引擎与死因；解析、状态与减伤；复盘、存档与 overlay。

## 标准

1. **规则只能来自通用依据**：OverlayPlugin LogGuide 对日志字段的定义、OverlayPlugin 源码（如 `LineCombatant.cs` 的写出规则）、游戏数据（技能说明、状态说明等）、游戏机制。样本只用来核对规则，不能当规则、数值表或某个副本的特例的来源。遇到全新的副本，只用这一场的数据也要算对。
2. **复盘必须和监控一样**（2026-10-07 决定）：监控时日志一条一条到，只能用已到达的行；要等后面的行才能定的，先给暂定值，后面的行到了再改。复盘按同样的顺序单遍重算，结果与监控逐行相同。
3. **团灭是结果，不是死因**（2026-10-07 决定）：每次死亡按自己的证据判（伤害、即死效果、坠落、场边），别人同时死不影响。
